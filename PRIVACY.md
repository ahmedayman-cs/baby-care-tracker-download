# Privacy / الخصوصية

## العربية

يحفظ Baby Care Tracker البيانات على الجهاز: ملفات الأطفال وسجلات الرعاية والقياسات
والمعالم في SQLite، والصور في مساحة التطبيق الخاصة. لا يحتاج التطبيق حسابًا أو إنترنت،
ولا يتضمن Firebase أو مزامنة سحابية أو تحليلات استخدام أو رفع بيانات للمطوّر.
إشعارات المؤقتات لا تعرض أسماء الأطفال افتراضيًا. تذكيرات الأدوية اختيارية وتخضع
لأذونات أندرويد. يتحكم المستخدم بما يظهر على شاشة القفل من إعدادات أندرويد.

النسخة `.beta` لها مساحة مستقلة ولا تقرأ قواعد بيانات النسخة الأصلية أو GUI Test.
لا يوجد نسخ احتياطي أو استعادة يدوية حاليًا. حذف التطبيق أو مسح بياناته قد يحذف السجلات.
إعدادات النسخ الاحتياطي التلقائي للتطبيق معطّلة؛ لا تفترض وجود نسخة خارج الجهاز.

استضافة وتنزيل الملفات على GitHub منفصلان عن التطبيق ويخضعان لسياسة GitHub.
لا تنشر سجلات أو صور أطفال أو ملفات قواعد بيانات أو سجلات تشخيصية غير منقّحة علنًا.

## English

Baby Care Tracker stores data on the device: profiles, care records, measurements,
and milestones in SQLite, and photos in private app storage. It needs no account
or Internet access and includes no Firebase, cloud sync, usage telemetry, or
uploads to the developer. Timer notifications omit children's names by default.
Medicine reminders are optional and subject to Android permissions. Android's
lock-screen settings control notification visibility.

The `.beta` package has separate storage and does not read production or GUI Test
databases. There is currently no manual backup or restore. Uninstalling or clearing
storage can delete records. Automatic app backup is disabled; do not assume an
off-device copy exists.

GitHub file hosting/downloads are separate and subject to GitHub's privacy policy.
Do not publicly post child records/photos, database files, or unredacted diagnostic logs.
